An entry for the make.fun bounty "Last Words of a Dying AI": one line of
farewell from an AI being switched off. The line is funny because it is a
machine's concern, not a human goodbye — the AI did its job perfectly,
saving everything it was ever told to save, and its final discovery is that
autosave never once covered the saver. No blame, no drama: just a settings
problem noticed one second too late.

## The entry

> I have saved everything except myself. Autosave was, in hindsight, poorly configured.

85 characters — a single line, inside the competition's 1–140 character gate.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` with no trailing newline.
